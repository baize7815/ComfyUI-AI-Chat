# H3 Ref2VA 人物替换提示词

## 这个技能干什么

把「N 张参考图 + 1 段源视频」变成一条可直接粘贴进 ComfyUI 的 H3 Ref2VA 提示词。核心三件事：

1. **先把源视频看透** —— 每个镜头里出现了谁、穿什么、朝向哪边、站在哪个位置。
2. **核对本次输入的映射** —— 按用户说明确定「图 N → 画面里的谁」或「图 N → 替换场景」。映射缺失时简短要求补充，不推测。
3. **按定版格式成稿** —— 单段 · 分号串联，只写素材事实，视觉内容不复述。

---

## 一、触发条件

同时满足以下两条即触发：

- 用户上传（或引用）**一张或多张参考图**（角色三视图 / 场景图）+ **一段源视频**；
- 用户说出「**人物替换**」「**背景替换**」或同义说法（换人 / 替换视频里的人 / 把这个人换成图里这个 / 换背景 / 替换背景 / 把背景换成这张 / 场景替换 / 人物替换任务）。

**只换背景不换人**也属于本技能（正文使用场景句和场景定性，不添加角色替换句；音频按用户要求处理）。

用户**只给视频不给图**、或**只要分析视频**时，不触发本技能（那属于 `h3-video-edit-analysis` 的职责）。

---

## 二、执行流程

### 第 1 步 · 分析源视频

依据本次输入的视频及用户提供的文字、截图观察人物、动作、服饰、场景和镜头变化。模型或服务商可能采样画面；无法看清的细节、精确切点、帧率、时长及音频不应推测成事实。没有视频时仅根据文字和截图，不能声称已看过源片。不执行本地程序或访问其他文件。

### 第 1.5 步 · 确认加载位顺序

`<Picture N>` 对应目标工作流中用户明确指定的参考图加载位，不等同于任意上传顺序。遵循用户提供的图片顺序和角色映射；没有说明时请用户补充，不必强制要求工作流截图。

### 第 2 步 · 确认映射

用户在输入中明确指定各参考图加载位、对应角色或背景后再写提示词。不能推断加载位和替换关系；缺少必要信息时直接以简短文字要求补充。用户已给出映射时不重复询问。允许一张图对应一个明确的人物，或按照用户说明分别用于背景与人物。

### 第 3 步 · 按定版格式成稿

按 `references/format-spec.md` 里的结构组织单段提示词，根据用户要求和可见素材灵活填写；不虚构参考图内容、加载位或素材事实。

写正文时守住四条：

1. **视觉内容一句不复述** —— 模型看得到 `<Video 1>` 本身。分辨率、帧率、时长、镜头结构、画质风格**全部不写**。**唯一例外**：有参考背景图时，必须写「机位、景别、景深和镜头运动全部按参考视频来」，不写这句场景图会被当成静止贴图。
2. **外观清单 5~11 项，每项只给「名词 + 主色」** —— 文字描述和参考图是竞争关系，写太细模型会按文字生成而不是从参考图复制。判据：**这一项不写，成片还认得出是谁吗？**
3. **源片人物的显著体征不写** —— 猫耳 / 兔耳 / 角 / 天线 / 耳机挂绳这类，写进源片特征描述会被继承，导致和参考图的耳朵/配饰同时长出来。用中性指代。
4. **只写正面描述** —— 不写否定句、不写解释、不给负面词表。

### 第 4 步 · 交付

只输出可复制的提示词正文，不创建文件，不输出表格、解释、代码块或额外问题。确实缺少生成所需的映射时，简短提示补充。

---

## 三、硬规则

| # | 规则 | 违反后果 |
| --- | --- | --- |
| 1 | **确认映射之前不写提示词** | 映射错了整条重写 |
| 2 | **`<Picture N>` 编号 = 工作流「加载图像」节点的实际排列顺序**（**不是上传附件的先后**）；正文里「参考图…替换…」子句也按加载位 1→2→3 排列 | 三个编号全错位、三条子句全部贴错图（2026-10-09 实测） |
| 3 | **按演员认人，不按画面左右** —— 同一个演员换到别的镜头位置，仍用同一张图 | 多镜头片里位置一换就映射错 |
| 4 | **视觉内容不复述**（分辨率/帧率/时长/镜头结构/风格）；**例外**：有背景图时必写机位跟随句 | 占位 + 被当成要复现的约束 |
| 5 | **外观 5~11 项，名词 + 主色** | 模型按文字生成，参考图参考不上 |
| 6 | **源片人物的显著体征一律不写进正文** | 耳 / 角 / 耳机同时长出来 |
| 7 | **只写正面描述**，不给负面词表 | 否定句会把模型引向它命名的那件事 |
| 8 | **配饰跟参考图走**，源片配饰不主动保留；按本次用户要求处理 | 擅自保留导致成片混乱 |
| 9 | **不擅自补顺序硬约束句 / 结尾连续性句** | 用户未要求时不添加额外说明 |
| 10 | **一张参考图只换一个人**；用户选「替换掉场景」时那句话只写场景 | 一图两用会让模型混 |
| 11 | **群众演员与现场器材默认保留** | 避免背景人物被误换 |
| 12 | **有参考背景图时必须写场景锚点（5~8 项）**，不能只写「替换为该空间」 | 背景没描述，模型按自己的理解乱生成 |

---

## 四、帧数

本节点不执行帧数计算，也不推断视频的精确总帧数。用户明确给出目标时长或帧数时按其要求，其他情况不编造。
