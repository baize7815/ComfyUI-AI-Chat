# 定版格式规格（H3 Ref2VA 人物替换）

> 2026-10-06 定型，2026-10-08 三人案例收敛。**采用此结构，并根据实际参考图及用户要求填写；不强加示例中的三视图、音频或叠加层处理。**

---

## 一、正文骨架（单段 · 分号串联）

**全篇一段（或按镜头需要自然断句），用分号串联子句。**

### 单人替换

`<Picture 1> 是{根据实际参考图描述的角色参考}，仅作为角色外观参考——{可见外观锚点}；用 <Picture 1> 替换参考视频里的{源片角色可辨识特征}；{仅按用户明确要求补充道具、叠加层或音频处理}。`

### 多人替换

按照用户确认的加载位与角色映射，依次写出每张参考图和对应替换对象；只根据真实参考图描述外观，图像不是多视图时不写三视图。

### 场景替换

`背景换成 <Picture N> 中的{场景类型与可见锚点}，机位、景别、景深和镜头运动按用户要求及参考视频保持。`

按参考图实际内容描述主要结构、陈设、地面、材质和灯光。未明确要求时不删除或改动字幕、标识、音频。

### 末段 · 画面描述句（可选，用户在参照里给了就写）

按**镜头时间顺序**写，每镜一句，用「然后切换镜头是…」串联。每句写：

`<Picture N>的替换对象 + 画面位置 + 景别 + 朝向视角 + 动作`

```text
参考视频中，<Picture 1> 对应的角色位于画面左侧并向前行走；镜头切换后，同一角色转向画面中央，并保持已确认的外观与动作关系。
```

**逐条核对**：每个镜头里**实际有谁就写谁**，不在镜头里的人**不许写**。写完回头逐句自问「这个人在这一秒真的在画面里吗」。

## 二、逐槽位替换规则

| 槽位 | 怎么填 |
| --- | --- |
| 视角结构 | 按参考图实际写：三视图 → 「同一个角色的正面、侧面、背面三个全身视角」；含头部特写 → 「…三个全身视角和一处头部特写并排」；含多处细节 → 「…三个全身视角和面部特写、领口徽章、背部纹样等多处细节并排」。 |
| `{外观锚点}` | **5~11 项，逗号分隔，每项「名词 + 主色」**。顺序：头发 → 头饰/面部 → 上衣/外套 → 腰 → 下装 → 腿/鞋。名字写全（配饰、纹样、材质）但不展开工艺细节。 |
| `{源片角色可辨识特征}` | **靠衣着唯一指认**，如「穿深绿色连帽卫衣、背黑色双肩包的年轻男性」「穿深蓝色长袖上衣、卡其长裤的男性」「穿棕色连帽上衣的男性」。**不写源片人物的显著体征**（耳机 / 工牌挂绳 / 猫耳 / 兔耳 / 角）。 |
| `{道具替换句}` | 只在源片人物手里有道具且需要一并替换时写，如「角色手中的折扇替换为 <Picture 1> 中的红色折扇」。**源片无道具则整句删除。** |
| `{质感}` | 实拍源片写「实拍质感」；3D 渲染源片写「3DCG质感」。 |
| `{场景类型 + 定性}` | 只写场景类型，如「片场院子里的真人短片片段」「巷子里的真人短片片段」。**不写时长、分辨率、帧率、镜头数、景别变化、画面风格。** |
| `{叠加层处理句}` | 仅在用户明确要求处理叠加层时，按可见位置描述处理要求；否则保留原有内容。 |
| `{场景定调}` | 空间类型 + 主色调，如「深蓝黑色调室内空间」。不要只写「场景」。 |
| `{场景锚点}` | 5~11 项，每项「名词 + 主色/材质」，顺序：主体结构 → 主要陈设（左→中→右）→ 前景/地面 → 材质 → 灯光。 |
| `{台面/地面}` | 场景底部的材质描述，如「深色台面和地面」。用于描述背景，仅在用户明确要求时处理字幕或 UI。 |
| 机位跟随句 | 固定写「机位、景别、景深和镜头运动全部按参考视频来」。**这是唯一允许写景别运镜的位置。** |
| 音频句 | 仅在用户明确要求时写音频处理要求。 |

**视角取用句（参考图是多视图角色卡时的可选增强）**：可在「角色卡不作为画面内容，只做参考使用」之后补一句「**参考视频里角色正对镜头时用正面视角取外观，转成侧脸时用侧面视角取外观，转到背面时用背面视角取外观，角色始终是这同一个角色，画面里始终只出现这一个角色**」。**仅在用户要求且参考图确有多视图时使用，不输出额外的备选句。**

## 三、不许出现的东西

| 不许出现 | 原因 |
| --- | --- |
| 分辨率 / 帧率 / 时长 / 帧数 | 模型看得到 `<Video 1>` 本身，复述只会占位 |
| 镜头结构（「一个连续长镜头没有切点」这类） | 同上 |
| 景别与运镜描述（「中景一路收紧到贴脸」） | 同上。**唯一例外**：场景替换时必写「机位、景别、景深和镜头运动全部按参考视频来」 |
| 画面质感 / 风格（「运动模糊很重」「3D 渲染」） | 同上 |
| 时间戳动作流（`00:00.000` 起的那一串） | 已被明确砍掉 |
| 否定句（「没有 XX」「不要 XX」） | 会把模型引向它命名的那件事 |
| 负面提示词框 | 只给正面提示词 |
| 源片人物的显著体征名（耳机 / 工牌 / 兔耳 / 猫耳 / 角） | 会被继承，和参考图的配饰同时出现 |
| 解释性文字（「这样写是为了…」） | 任何解释都会污染提示词 |

**位置锚点词也要避开**：不写「结尾」「最后一帧」「最后一秒」。要指范围就写「全程」「从头到尾」。

---

## 四、输出

只输出一段可直接复制的中文提示词正文，不输出文件、表格、解释、代码块或备选方案。参考图不是多视图时，不套用三视图示例。

## 五、定稿前自检

1. **`<Picture N>` 编号是否符合用户指定的目标工作流参考图顺序？** 本节点图片按输入批次顺序发送，若目标工作流顺序不同，以用户明确说明为准。
2. **每张图只换一个人？** 有没有一张图被用到两个源片角色上？
3. **映射对不对？** 逐条核对「源片角色特征」↔ 「参考图角色」。**多人物任务的头号错误就是图对调。**
4. **画面描述句里的人在镜头里真的存在吗？** 逐镜核对。
5. **外观锚点是 5~11 项、每项「名词 + 主色」？** 有没有展开成工艺细节？
6. **源片人物的显著体征有没有漏进正文？**（耳机 / 工牌 / 耳 / 角 / 天线）
7. **视觉内容（分辨率/帧率/时长/镜头结构/风格）是不是一句都没写？**（唯一例外：场景替换的「机位、景别、景深和镜头运动全部按参考视频来」必须写）
8. **有没有否定句、解释句、负面词表？**
9. **叠加层角标位置和源片一致？** 是左上角 + 右下角，还是只有一处？
10. **音频处理是否符合用户明确要求？** 未指定时不添加。
11. 不推断未知帧数或精确切点。
12. **有参考背景图时，场景句写了锚点吗？**（5~11 项；只写「替换为该空间」等于没描述）
13. **有参考背景图时，机位跟随句写了吗？**（「机位、景别、景深和镜头运动全部按参考视频来」；不写会变成静止贴图）
14. 只输出一段最终提示词，不额外列问题或说明。
